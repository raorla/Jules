# Ce que tu décides

- `type` : `bug`, `feature`, `refactor`, `chore`, `docs`, `test` ou `security`.
- `size` : `S` (≤ 100 lignes, ≤ 3 fichiers), `M` (≤ 400 lignes, ≤ 10 fichiers), `L` au-delà. Pour `L`, propose un découpage en sous-issues (`splitProposal`) : Jules ne code pas une tâche `L`.

- `ready` : la Definition of Ready est-elle satisfaite ?

  - aucune décision produit n'est ouverte (choix d'interface, de tarif…).
- Si `ready` est faux, mets dans `questions` les questions précises qui débloqueraient la tâche (5 au maximum).
