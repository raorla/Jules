# Décisions d'architecture (ADR)

Une décision structurante = un ADR, ajouté dans la PR qui l'applique ([CONTRIBUTING.md](../../CONTRIBUTING.md)). La liste des décisions déjà prises, encore à rédiger ici, est dans [ARCHITECTURE.md §23](../../ARCHITECTURE.md#23-décisions-à-formaliser-docsadr).

Nom du fichier : `NNNN-titre-court.md`, avec le numéro de §23 quand il existe.

## Modèle

```markdown
# NNNN — Titre

- Statut : proposé | accepté | remplacé par NNNN
- Date : AAAA-MM-JJ

## Contexte

Le problème, les contraintes, ce qui oblige à décider maintenant.

## Décision

Ce qu'on fait, en une ou deux phrases, puis les détails utiles.

## Conséquences

Ce que ça rend plus simple, ce que ça rend plus difficile, ce qu'il faudra surveiller.

## Options écartées

Chaque option sérieuse et pourquoi elle n'a pas été retenue.
```
